# JetSki / Antigravity Agent Customizations

This directory contains workspace-level customizations for JetSki and
Antigravity AI agents.

## Structure

- **`agents/`**: Custom agent and subagent definitions (`<agent_name>.md` or
  `<agent_name>/agent.json`).
- **`skills/`**: Multi-step procedures, runbooks, and workflow packages
  (`<skill_name>/SKILL.md`).
- **`rules/`**: Contextual and glob-based coding style and architectural rules
  (`*.md`).
- **`scripts/`**: Automation, linting, and verification scripts for agents
  (`80-col.py`, `check-endpoints.py`, `precommit.py`, etc.).
